# Ograniczenia i rozwój

- Schemat API PSE należy zweryfikować z aktualną mapą endpointów.
- Częstotliwość i strefy czasowe danych obu źródeł mogą się różnić.
- Pojedyncza lokalizacja pogodowa nie reprezentuje całej Polski.
- Dane reanalizy Open-Meteo są estymacją modelową, a nie zawsze bezpośrednim pomiarem stacyjnym.
- Korelacja nie dowodzi przyczynowości.
- Dalszy rozwój: agregacja kilku lokalizacji, przyrostowe ładowanie, historia uruchomień, PostgreSQL/Parquet, monitoring i dashboard.
